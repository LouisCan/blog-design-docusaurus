# 计划：新增导航栏 Tutorial2（内容指向 docs2 目录）

## 概述

在现有 Docusaurus 站点（`cancloude/`）中新增第二个文档区 "Tutorial2"，内容存放在 `docs2/` 目录，导航栏出现 "Tutorial2" 入口，路由前缀为 `/docs2`。

Docusaurus 的 preset-classic 只内置一个 docs 实例，因此第二个文档目录必须通过 `plugins` 中额外注册一个 `@docusaurus/plugin-content-docs` 实例来实现。

## 现状分析

- 配置文件：`cancloude/docusaurus.config.js`
  - 使用 `presets: [['classic', {docs: {sidebarPath: './sidebars.js', ...}, ...}]]`，即默认 docs 插件实例（`id: 'default'`，path 为 `docs/`，routeBasePath 为 `/docs`）
  - navbar items 中 Tutorial 是 `{type: 'docSidebar', sidebarId: 'tutorialSidebar', position: 'left', label: 'Tutorial'}`（第 91-104 行）
- 侧边栏：`cancloude/sidebars.js` 仅定义 `tutorialSidebar: [{type: 'autogenerated', dirName: '.'}]`
- 文档目录：目前只有 `cancloude/docs/`，不存在 `docs2/`
- 版本：Docusaurus 3.10.2

## 变更内容

### 1. 新建 `cancloude/docs2/intro.mdx`（示例文档）

docs 插件实例要求目录内至少有一个文档，否则构建报错。创建一个最简示例：

```mdx
---
sidebar_position: 1
---

# Tutorial2 Intro

这是 docs2 目录的第一个文档。

```

### 2. 修改 `cancloude/sidebars.js`

为第二个 docs 实例新增 sidebar 定义（两实例共用同一个 sidebars.js，各自按 key 取用，这是 Docusaurus 官方推荐做法）：

```js
const sidebars = {
  tutorialSidebar: [{type: 'autogenerated', dirName: '.'}],
  tutorial2Sidebar: [{type: 'autogenerated', dirName: '.'}],
};
```

`dirName: '.'` 相对的是该插件实例自己的 `path`（即 `docs2/`），不会与第一个实例冲突。

### 3. 修改 `cancloude/docusaurus.config.js`

**a) 在 `presets` 同级添加 `plugins`，注册第二个 docs 插件实例：**

```js
plugins: [
  [
    '@docusaurus/plugin-content-docs',
    /** @type {import('@docusaurus/plugin-content-docs').Options} */
    ({
      id: 'docs2',
      path: 'docs2',
      routeBasePath: 'docs2',
      sidebarPath: './sidebars.js',
    }),
  ],
],
```

- `routeBasePath` 必须与默认实例的 `docs` 不同，否则路由冲突
- 插件已随 preset-classic 安装，无需新增依赖

**b) 在 `themeConfig.navbar.items` 的 Tutorial 项之后新增：**

```js
{
  type: 'docSidebar',
  sidebarId: 'tutorial2Sidebar',
  position: 'left',
  label: 'Tutorial2',
},
```

`docSidebar` 类型的导航项通过全局唯一的 sidebarId 自动关联到第二个插件实例。

## 假设与决策

- 路由前缀取 `docs2`（与目录名一致，访问地址为 `/docs2/intro`）
- 不为 docs2 单独新建 sidebars 文件，共用 `sidebars.js`（文件更少，符合官方示例）
- 不配置 `editUrl`，Tutorial2 文档暂无 "edit this page" 链接（可后续按需添加）
- footer 不改动（如需要可后续把 Tutorial2 加到 footer 链接）

## 验证步骤

1. `cd cancloude && npm run start`
2. 确认导航栏出现 "Tutorial2"，点击跳转到 `/docs2/intro`
3. 确认左侧出现 `tutorial2Sidebar` 自动生成的侧边栏
4. 确认原 Tutorial（`/docs/intro`）与 Blog 正常不受影响
5. `npm run build` 通过（无路由冲突、无断链）
